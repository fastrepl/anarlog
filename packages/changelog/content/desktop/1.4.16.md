## Transcription

- Download Whisper, Parakeet, and local LLM models from Anarlog's own model host; this also fixes the broken Whisper Large Turbo download
- See **On-device file** in Settings → Transcription when you want to use a
  whisper.cpp `.bin` model you already have, instead of the older **Local
  file** label
- Pick that file from **Choose a .bin model** on the same row
- Point **Custom**, or Deepgram's **Advanced** base URL, at a
  Deepgram-compatible server on this computer or your local network
- Read the four on-device paths — Soniqo, Apple Speech, an on-device `.bin`,
  and a local Deepgram-compatible server — in the
  [on-device models FAQ](https://docs.anarlog.so/help#use-on-device-models)
