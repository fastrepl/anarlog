summary: "Anarlog 2.0 moves the desktop app to a native GPUI interface, removes the Cloud Sync device limit, and upgrades seamlessly from 1.4.36."
---

- Rebuilt the Anarlog desktop app on a native GPUI interface across macOS, Windows, and Linux with no embedded WebView, a sharper square visual design, and instant transitions.
- Preserve your existing notes, transcripts, audio recordings, encrypted Cloud Sync keys, account sign-in, pinned tabs, settings, and bundled `anarlog` CLI automatically when upgrading from Anarlog 1.4.36.
- Open notes in standalone native windows, zoom the interface (`Cmd/Ctrl +`, `-`, `0`), and install future updates automatically through the built-in native updater on macOS, Windows, and Linux.
- Remove the 5-device Cloud Sync limit on Anarlog Pro so you can sync unlimited devices across desktop and mobile without extra device add-ons.
- View your local **Data location** in Storage settings with an **Open folder** button (and a separate database path when stored elsewhere), alongside cleaner settings pages and inline permission statuses.

## Linux

- Start cleanly without a system tray icon when appindicator libraries are unavailable instead of crashing on launch.
