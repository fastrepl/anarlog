## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-get-state`
- `allow-set-enabled`
- `allow-set-auto-switch`
- `allow-set-background`
- `allow-add-extension`
- `allow-allow-camera`
- `allow-open-extension-settings`
