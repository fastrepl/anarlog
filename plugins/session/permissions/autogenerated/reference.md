## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-create-session`
- `allow-create-session-for-event`
- `allow-soft-delete-session`
- `allow-restore-deleted-session`
- `allow-add-session-participant`
- `allow-remove-session-participant`
- `allow-persist-chat-session-proposal`
- `allow-set-session-proposal-status`
- `allow-resolve-session-conflicts`
- `allow-resolve-session-conflict`
- `allow-move-session-contents`
- `allow-catalog-note-attachment`
- `allow-catalog-session-audio`
- `allow-mark-session-audio-transcription-complete`
- `allow-set-attachment-cloud-sync-enabled`
- `allow-tombstone-session-audio`
- `allow-mark-session-audio-absent`
- `allow-catalog-folder-material`
- `allow-tombstone-folder-material`
- `allow-ensure-folder-catalog`
- `allow-rename-folder-catalog`
- `allow-delete-folder-catalog`
- `allow-update-folder-instructions`
- `allow-update-folder-workspace`
- `allow-update-folder-icon`
