## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-check`
- `allow-download`
- `allow-install-and-relaunch`
- `allow-is-downloaded`
- `allow-maybe-emit-updated`
- `allow-set-automatic-updates-enabled`
- `allow-set-meeting-active`
