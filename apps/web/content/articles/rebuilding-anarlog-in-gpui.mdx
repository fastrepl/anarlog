Anarlog 2.0 replaces Tauri and system WebViews with a single-process Rust UI built on GPUI (`apps/desktop-gpui`), keeping local SQLite as storage (Markdown is export only). Here is how shipping `1.4.35` compares against GPUI across fresh macOS, Linux, and Windows VMs plus the signed `1.4.36` vs `2.0.0` Apple Silicon production build.

## What the harness caught

- **GPUI wheel-scroll stalls:** Early candidates took `101.37 s` across `1,014` Windows wheel events (vs `9.28 s` on `1.4.35`, where WebView2 skipped `70.14%` of frames as blank bands) and hit an ~`18 s` macOS `CAMetalDisplayLink` stall. Fixed before `2.0.0` in PR `#8236` (Windows down to `14.9 s`) and PR `#8242`.
- **Tauri `1.4.35` save-on-quit race:** `0/5` full 500-char Linux edits survived process quit in `1.4.35` (vs `5/5` in GPUI) because exit beat the debounced SQLite flush. Fixed in PR `#8238` and shipped in `1.4.36`.
- **Headless Linux software-Vulkan resize:** Continuous resizing under Mesa `lavapipe` added `+48.1%` CPU (chart above) while still cutting memory `-84.9%`.

## Fixture and scope

Fixture: `5,000` notes (`2,500` summaries, `1` `20,000`-word stress note), signed out, sync off, Light theme, `1280x800` window on a macOS `26.6.2` VM (12c M4 Pro Virtual), Ubuntu `22.04`/`24.04` KVM (8c Xeon), and Windows Server `2022` (8c Xeon). Live audio capture, STT, local LLM inference, and CloudSync add their own budgets when active.
